# dashboard/

Panel web de **monitoreo y control** del sistema: estado de cada zona, lecturas de los sensores, historial y botones para sobrescribir el control (encender o apagar manualmente).

El panel **no habla directo con el ESP32**: se comunica a través del backend / broker. Así funciona igual con Wokwi y con la placa física.
